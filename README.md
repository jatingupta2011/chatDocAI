# ChatDoc AI

An AI-powered document intelligence platform built with Spring Boot, React, Spring AI, ChromaDB, and OpenRouter.

## Features

- Upload PDF
- Extract Text
- Intelligent Chunking
- Semantic Search
- AI Chat
- Page References

## Tech Stack

- Spring Boot
- Spring AI
- React
- ChromaDB
- OpenRouter
- Docker
